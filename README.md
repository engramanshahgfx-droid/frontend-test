## Quick Start

```bash
# 1. Install Dependencies
npm install

# 2. Configure Environment (.env.local)
NEXT_PUBLIC_API_BASE_URL=http://localhost:8000/api

# 3. Run Development Server
npm run dev
```

Visit `http://localhost:3000` to view the application.
